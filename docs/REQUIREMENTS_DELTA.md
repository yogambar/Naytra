## Delta Template

When a delta is identified, add a new entry below using this template:

---

### Δ-NNN: Short Title

| Field | Value |
| --- | --- |
| **Date** | YYYY-MM-DD |
| **Milestone** | M? |
| **Spec says** | What the master prompt / specification requires |
| **Implementation does** | What was actually built and why |
| **Reason** | Technical constraint / owner decision / scope change / dependency issue |
| **Impact** | What is affected — features, timelines, other milestones |
| **Resolution** | Accepted / Will fix in M? / Deferred to Phase 2 |
| **Owner approval** | Yes / Pending |
